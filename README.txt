干支暦 PWA - 設置手順
========================

このフォルダには次の4ファイルが入っています。
- index.html   ... カレンダー本体
- manifest.json ... PWA設定
- sw.js        ... オフライン用キャッシュ
- icon-192.png / icon-512.png ... アイコン

【重要】PWAとしてホーム画面に追加するには、
file:// で直接開くのではなく、https:// で配信されている必要があります。
以下はどちらも無料です。

■ 方法1: Netlify Drop（一番簡単、アカウント登録も不要）
1. https://app.netlify.com/drop を開く
2. この4ファイルが入ったフォルダをそのままドラッグ&ドロップ
3. 発行されたURL（https://xxxx.netlify.app）にスマホでアクセス
4. Safari: 共有ボタン → 「ホーム画面に追加」
   Chrome: メニュー → 「アプリをインストール」

■ 方法2: GitHub Pages（無料・恒久的に使いたい場合向け）
1. GitHubで新しいリポジトリを作成
2. この4ファイルをアップロード
3. リポジトリの Settings → Pages で公開を有効化
4. 発行されたURLにスマホでアクセスし、方法1の手順4と同様に追加

どちらも数分で終わります。迷ったら方法1（Netlify Drop）がおすすめです。
